== Description ==
Appointment Booking Pro provides the foundation for a Persian-first booking system with configurable calendar, working hours and booking slots.

== Installation ==
1. Upload the appointment-booking-pro folder to /wp-content/plugins/
2. Activate the plugin.
3. Open نوبت‌دهی from WordPress admin.
