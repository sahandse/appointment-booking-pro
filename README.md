# نوبت‌دهی حرفه‌ای وردپرس

افزونه نوبت‌دهی حرفه‌ای با رابط فارسی و مینیمال، مناسب خدمات، کلینیک‌ها، سالن‌ها، مشاوره، آموزش و کسب‌وکارهای خدماتی.

## ویژگی‌ها
- ثبت نوبت با تاریخ و ساعت
- تقویم شمسی/میلادی
- مدیریت خدمات و پرسنل
- روزها و ساعات کاری
- تعطیلات هفتگی و مناسبت‌ها
- یادآوری و اعلان
- اتصال WooCommerce برای بیعانه
- QR نوبت
- پنل مشتری و پرسنل
- آماده اتصال Google Calendar
- معماری مناسب توسعه Elementor Widget و SMS
